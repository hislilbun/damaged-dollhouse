Data & Backups

✦ Complete Dollhouse Backup

A full snapshot of supported app data and preferences. Restore replaces the included storage categories.

🖤 Damaged Dollhouse unified backup includes Pretty Little Problems check-ins, drafts, System Directory, profile links, journals, and appearance preferences. Restore replaces all nine app storage categories with the snapshot in the file. Export your current data first; this does not merge.

♡ Profile Links

✧ Pretty Little Problems Backups

Back up check-ins and drafts, or export compatible JSON and CSV files.

Use the full backup for multiple check-ins. The original JSON export below is retained for compatibility but only contains the original one-entry-per-date records.

Restore merges by date and replaces entries on matching dates, after confirmation. JSON preserves all responses; CSV is useful for spreadsheets. Backup files contain sensitive information in readable text.

⌂ Privacy & Local Storage

Your entries are stored on this device, not in a cloud account.

Important: Data is saved in this browser's local storage on this device. It is not encrypted. Anyone with access to your browser profile/device may be able to read it. Private browsing, clearing site data, changing browsers, or losing the device can erase entries. Make regular backups and store them somewhere private.

⚠ Danger Zone

These actions permanently erase locally stored records. Export a backup first.
